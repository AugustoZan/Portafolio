Resolva

Resolva — Sistema de gestión de incidentes industriales que permite reportar fallas desde el celular, asignar responsables y hacer seguimiento en tiempo real. Arquitectura frontend modular en React + TypeScript + Vite, con React Router para navegación protegida por roles (operador, técnico, supervisor, gerente) y Context API para el manejo global de autenticación y estado. Integración con API REST desplegada en Render mediante y más de 15 componentes reutilizables (tablas, gráficos de barras, KPIs, modales y formularios). Trabajé en equipo de 5 personas, a cargo del desarrollo frontend, implementando metodologías ágiles y preparando la capa de servicios para una conexión backend real con JWT y validación por roles.
